## 🧑‍💻 How to Use

**1. Clone the repository**

```bash
git clone https://github.com/your-username/Strivers-A2Z-Java.git
```

**2. Navigate to the repository**

```bash
cd Strivers-A2Z-Java
```

**3. Compile and run a specific Java file**

```bash
javac 01_Arrays/01_Linear_Search.java
java -cp 01_Arrays 01_Linear_Search
```

You can use any Java IDE like IntelliJ IDEA, Eclipse, or VS Code.
